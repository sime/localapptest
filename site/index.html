How this works
  1. The page is served over HTTPS from a public origin. The target is plain HTTP on a host that resolves to a private IP (10.x).
  2. fetch() is called with targetAddressSpace. Chrome treats the request as an intentional local-network request: it skips the mixed-content block and shows the Local Network Access permission prompt (Chrome 142+).
  3. Older Chrome (Private Network Access) sends a preflight with Access-Control-Request-Private-Network: true. The server must answer Access-Control-Allow-Private-Network: true.
  4. The server must always return Access-Control-Allow-Origin: https://sime.github.io (or *).
  5. Safari and Firefox don't support targetAddressSpace, so they block HTTPS→HTTP as mixed content.
